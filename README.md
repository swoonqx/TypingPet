# 🐾 Typing Pet

**키보드를 칠 때마다 캐릭터가 손을 번갈아 들며 통통 튀는 Windows용 데스크톱 펫입니다.**

원하는 이미지를 사용해 나만의 캐릭터를 만들 수 있으며,  
GIF / APNG 애니메이션, 키·마우스 패턴, 프리셋, 멀티 펫 기능을 지원합니다.

> **Latest Version: v4.1**

[📥 최신 버전 다운로드](https://github.com/swoonqx/TypingPet/releases/download/v4.1/TypingPet_v4.1.zip) · [📝 업데이트 내역](CHANGELOG.md)

---

## ✨ 주요 기능

- ⌨️ 키보드 입력에 맞춰 캐릭터가 움직입니다.
- 🖼️ 원하는 이미지로 캐릭터를 변경할 수 있습니다.
- 🎞️ **PNG / JPG / GIF / APNG**를 지원합니다.
- 🎯 특정 키, 키 조합, 기능키 또는 마우스 클릭에 반응하는 **패턴을 최대 10개**까지 등록할 수 있습니다.
- ✍️ 스타일러스 펜 및 터치 입력을 클릭 패턴으로 사용할 수 있습니다.
- 💾 최대 3개의 **프리셋**을 저장할 수 있습니다.
- 🐾 기본 펫 포함 **최대 3마리의 멀티 펫**을 동시에 띄울 수 있습니다.
- 🪟 여러 펫이 겹쳤을 때 표시 순서를 조절할 수 있습니다.
- 🌐 **한국어 / English / 日本語 / 简体中文**을 지원합니다.
- 🛠️ 오류 발생 시 `%AppData%\TypingPet\error.log`에 원인이 기록됩니다.
- 🔒 입력한 키의 내용은 저장하거나 전송하지 않습니다.
- 🌐 프로그램 자체는 인터넷에 접속하지 않습니다.

# 🆕 v4.1 업데이트

## 개선 / 추가

- **패턴 최대 10개**
  - 기존 3개에서 최대 10개로 늘어났습니다.
  - 이미지 설정 탭의 패턴 영역이 접고 펼 수 있는 스크롤 목록으로 변경되었습니다.
  - 패턴 미리보기는 작은 크기로 표시됩니다.

- **기능키 단독 트리거**
  - `Shift`, `Ctrl`, `Alt`, `CapsLock`, `Tab`을 단독 패턴 트리거로 등록할 수 있습니다.
  - `Shift`, `Ctrl`, `Alt`는 누른 뒤 다른 키 없이 떼면 단독 키로 등록됩니다.
  - 다른 키와 함께 누르면 `Ctrl + A`와 같은 조합 키로 등록됩니다.

- **중복 트리거 방지**
  - 다른 패턴에서 이미 사용 중인 키, 키 조합 또는 클릭은 중복으로 등록되지 않습니다.

- **스타일러스 펜 / 터치 지원**
  - 액정 타블렛이나 판타블렛의 펜 끝 누름 및 터치 입력을 왼쪽 클릭 등의 클릭 패턴으로 인식할 수 있습니다.

- **멀티 펫 겹침 순서**
  - 펫을 클릭하거나 드래그하면 해당 펫이 맨 앞으로 이동합니다.
  - 각 펫의 우클릭 메뉴에서 **맨 앞으로 가져오기**를 사용할 수 있습니다.
  - 기본 펫 우클릭 메뉴 및 트레이 메뉴의 **멀티 펫 겹침 순서**에서 전체 순서를 변경할 수 있습니다.

- **오류 기록**
  - 프로그램에서 문제가 발생하면 아래 파일에 오류 원인이 기록됩니다.

```text
%AppData%\TypingPet\error.log
```

- 프로그램 내 **4개 언어 설명서**가 v4.1 기능에 맞게 업데이트되었습니다.

## 수정

- Discord 화면 공유 등으로 화면이 느려질 때 키 입력 없이 펫이 위아래로 계속 떨리던 문제를 수정했습니다.
- 펫이 튀어 오르는 최대 높이를 제한하여 비정상적으로 크게 움직이는 현상을 방지했습니다.
- **항상 위에 고정** 상태에서 여러 펫을 겹쳐 놓았을 때 서로 앞으로 올라오려고 표시 순서가 반복해서 바뀌던 문제를 수정했습니다.
- 이미지 파일에 문제가 있는 경우에도 설정 창을 열 수 있도록 보호 처리를 강화했습니다.

자세한 버전별 변경사항은 [`CHANGELOG.md`](CHANGELOG.md)에서 확인할 수 있습니다.

# 🚀 실행

`TypingPet.exe`를 실행하면 화면 오른쪽 아래에 캐릭터가 나타나고 Windows 시스템 트레이에 Typing Pet 아이콘이 생성됩니다.

처음 직접 실행한 경우 설정 창이 한 번 자동으로 열립니다.

> Windows 시작 프로그램을 통해 자동 실행된 경우에는 설정 창이 자동으로 열리지 않습니다.

# 🖱️ 기본 사용법

캐릭터를 마우스로 드래그하면 원하는 위치로 이동할 수 있습니다.

**트레이 아이콘 또는 데스크톱 펫을 우클릭**하면 다음 메뉴를 사용할 수 있습니다.

| 메뉴 | 기능 |
|---|---|
| **설정...** | 설정 창을 엽니다. |
| **크기** | 작게 / 보통 / 크게 / 아주 크게 |
| **항상 위에 고정** | 다른 창보다 항상 위에 표시합니다. |
| **위치 잠금** | 마우스 입력이 캐릭터를 통과하며 드래그 이동을 막습니다. |
| **위치 초기화** | 캐릭터를 화면 오른쪽 아래로 되돌립니다. |
| **멀티 펫 겹침 순서** | 여러 펫이 겹쳐 있을 때 표시 순서를 변경합니다. |
| **종료** | Typing Pet을 종료합니다. |

추가로 띄운 펫을 우클릭하면 **맨 앞으로 가져오기** 및 **이 펫 숨기기** 등의 기능을 사용할 수 있습니다.

## ⚙️ 기본 설정

### 크기

캐릭터의 표시 크기를 설정합니다.

- 작게
- 보통
- 크게
- 아주 크게

### 항상 위에 고정

켜면 캐릭터가 다른 창보다 항상 위에 표시됩니다.

끄면 일반적인 창처럼 다른 프로그램 뒤로 이동할 수 있습니다.

### 위치 잠금

켜면 마우스 클릭이 캐릭터를 통과하며 캐릭터를 드래그해서 이동할 수 없게 됩니다.

### 위치 초기화

캐릭터를 화면 오른쪽 아래의 기본 위치로 되돌립니다.

## 💫 흔들림

타이핑할 때 캐릭터가 움직이는 정도를 설정합니다.

| 설정 | 동작 |
|---|---|
| **없음** | 위치는 움직이지 않고 이미지만 바뀝니다. |
| **1단계** | 약하게 움직입니다. |
| **2단계** | 중간 정도로 움직입니다. |
| **3단계** | 가장 크게 움직입니다. 기존 방식과 같은 움직임입니다. |

v4.1에서는 화면이 느려지는 상황에서 키 입력 없이 펫이 계속 떨리는 현상을 수정하고, 펫이 튀어 오르는 최대 높이를 제한했습니다.

---

## 🪟 작업표시줄에 표시

켜면 Windows 작업표시줄에 **Typing Pet 버튼**이 생성됩니다.

- 시스템 트레이 아이콘은 그대로 유지됩니다.
- 작업표시줄 버튼에서 `닫기`를 누르면 Typing Pet이 종료됩니다.
- 기본값은 **꺼짐**입니다.

멀티 펫으로 띄운 캐릭터에도 각각 작업표시줄 버튼이 생성됩니다.

추가 펫의 작업표시줄 버튼에서 `닫기`를 선택하면 전체 프로그램이 종료되는 대신 **해당 펫만 사라집니다.**

---

## 🚀 컴퓨터 시작 시 자동 실행

켜면 Windows 로그인 시 Typing Pet이 자동으로 실행됩니다.

- Windows 시작 프로그램에 등록됩니다.
- 기본값은 **꺼짐**입니다.
- 자동 실행된 경우 설정 창은 자동으로 열리지 않습니다.
- 기능을 끄면 시작 프로그램 등록도 해제됩니다.
- `Windows 설정 → 앱 → 시작 프로그램`에서도 직접 끌 수 있습니다.

> [!WARNING]
> Typing Pet을 **관리자 권한으로 실행하도록 설정한 경우**, Windows의 보안 정책으로 인해 로그인 시 자동 실행 기능이 정상적으로 동작하지 않을 수 있습니다.

# 🖼️ 이미지 설정

`설정 → 이미지 설정`에서 다음 이미지를 변경할 수 있습니다.

- 기본
- 왼손
- 오른손
- 패턴 이미지

### 지원 형식

| 형식 | 지원 |
|---|:---:|
| PNG | ✅ |
| JPG / JPEG | ✅ |
| GIF | ✅ |
| APNG | ✅ |

투명한 배경이 필요한 경우 **투명 PNG 또는 APNG** 사용을 권장합니다.

### 권장 이미지 크기

**800 × 500 px**

기본 / 왼손 / 오른손 이미지는 동일한 캔버스 크기와 동일한 위치 기준으로 제작하면 가장 자연스럽게 움직입니다.

화면에 표시되는 캐릭터의 크기와 비율은 **기본 이미지**를 기준으로 정해집니다.

`기본값` 버튼을 누르면 원래 이미지로 되돌릴 수 있습니다.

> [!NOTE]
> 이미지 파일에 문제가 있는 경우에도 설정 창을 열 수 있도록 v4.1에서 보호 처리가 강화되었습니다.

# 🎞️ GIF / APNG

움직이는 GIF 및 APNG 이미지를 캐릭터로 사용할 수 있습니다.

패턴 이미지에도 동일하게 사용할 수 있습니다.

키 입력 등에 의해 이미지가 변경될 때마다 애니메이션은 **첫 프레임부터 다시 재생**됩니다.

### 제한

| 항목 | 제한 |
|---|---:|
| 파일 크기 | **15 MB 이하** |
| 프레임 수 | **300 프레임 이하** |

이미지 크기가 크거나 프레임 수가 많을수록 메모리 사용량이 증가할 수 있습니다.

# 🎯 패턴 기능

특정 키, 키 조합, 기능키 또는 마우스 입력에 반응하는 별도의 이미지를 설정할 수 있습니다.

패턴은 **최대 10개**까지 등록할 수 있습니다.

v4.1부터 패턴 목록은 **접고 펼 수 있는 스크롤 목록**으로 표시되며, 각 패턴의 미리보기는 작은 크기로 표시됩니다.

## 패턴 등록 방법

1. `설정 → 이미지 설정`을 엽니다.
2. `+ 패턴 추가`를 누릅니다.
3. `트리거` 버튼을 누릅니다.
4. 원하는 키, 키 조합 또는 마우스 클릭을 입력합니다.
5. `이미지 변경`으로 표시할 이미지를 선택합니다.

패턴 이미지도 `이미지 변경` 및 `기본값` 기능으로 수정할 수 있습니다.

프리셋을 저장하면 **트리거와 패턴 이미지도 함께 저장**됩니다.

평소에는 왼손/오른손 이미지가 번갈아 나타나며, 등록된 트리거를 입력한 순간 패턴 이미지가 표시됩니다.

다른 키를 입력하면 다시 일반적인 동작으로 돌아갑니다.

## 기능키 단독 등록

다음 기능키를 단독 트리거로 사용할 수 있습니다.

- `Shift`
- `Ctrl`
- `Alt`
- `CapsLock`
- `Tab`

`Shift`, `Ctrl`, `Alt`는 키를 누른 뒤 **다른 키를 누르지 않고 떼면 단독 트리거**로 등록됩니다.

다른 키와 함께 입력하면 조합 트리거로 등록됩니다.

예:

```text
Ctrl
Ctrl + A
Shift
Shift + S
```

## 중복 트리거 방지

이미 다른 패턴에서 사용 중인 키, 키 조합 또는 클릭은 다른 패턴에 중복으로 등록할 수 없습니다.

## 마우스 / 스타일러스 / 터치

등록한 마우스 클릭은 패턴 트리거로 사용할 수 있습니다.

v4.1부터 액정 타블렛 및 판타블렛의 **스타일러스 펜 끝 누름**과 **터치 입력**도 왼쪽 클릭 등의 클릭 패턴으로 인식할 수 있습니다.

> [!NOTE]
> 마우스 클릭은 **패턴으로 등록된 클릭만** 캐릭터에 영향을 줍니다.  
> 등록하지 않은 일반적인 클릭은 캐릭터 동작에 영향을 주지 않습니다.

# 💾 프리셋

현재 이미지와 패턴 설정을 **최대 3개**까지 저장할 수 있습니다.

## 저장

1. `프리셋 설정` 탭을 엽니다.
2. 프리셋 1~3 중 원하는 슬롯을 선택합니다.
3. 프리셋 이름을 입력합니다.
4. `현재 설정 저장`을 누릅니다.

프리셋 이름은 **최대 16자**까지 사용할 수 있습니다.

이미 저장된 슬롯에 다시 저장하면 덮어쓸 것인지 확인합니다.

## 적용

`적용` 버튼을 누르면 해당 프리셋이 현재 기본 펫에 적용됩니다.

## 수정

저장된 프리셋에서는 각 이미지를 따로 수정할 수 있습니다.

- **이미지 변경** — 선택한 이미지만 변경
- **기본값** — 해당 이미지를 기본 이미지로 초기화
- **패턴 삭제** — 선택한 패턴 제거
- **이름 변경** — 프리셋 이름 변경
- **삭제** — 프리셋 삭제

프리셋에서 변경한 내용은 우선 **해당 프리셋에만 저장**됩니다.

기본 펫에도 적용하려면 `적용` 버튼을 눌러주세요.

# 🐾 멀티 펫

저장한 프리셋의 캐릭터를 데스크톱에 추가로 띄울 수 있습니다.

프리셋의 **펫 띄우기** 버튼을 누르면 해당 프리셋의 캐릭터가 나타납니다.

펫을 띄우면 버튼은 **펫 숨기기**로 변경되며 다시 누르면 해당 펫이 사라집니다.

### 동시에 사용할 수 있는 펫

**기본 펫 포함 최대 3마리**

추가한 펫도 기본 펫과 같은 키 입력에 함께 반응합니다.

각 펫은 자신이 연결된 프리셋에 저장된 이미지와 패턴을 사용합니다.

다음 설정은 기본 펫의 설정을 함께 따릅니다.

- 크기
- 흔들림
- 항상 위에 고정
- 위치 잠금

추가 펫도 마우스로 자유롭게 이동할 수 있으며 위치가 저장되어 다음 실행 시 이전 위치에 다시 나타납니다.

프리셋의 이미지를 수정하면 현재 띄워져 있는 해당 펫에도 바로 반영됩니다.

프리셋을 삭제하면 해당 프리셋으로 띄운 펫도 함께 사라집니다.

## 멀티 펫 겹침 순서

v4.1부터 여러 펫이 겹쳤을 때 표시되는 순서를 조절할 수 있습니다.

- 펫을 **클릭하거나 드래그하면 해당 펫이 맨 앞으로** 이동합니다.
- 각 펫의 우클릭 메뉴에서 **맨 앞으로 가져오기**를 사용할 수 있습니다.
- 기본 펫의 우클릭 메뉴 또는 트레이 메뉴에서 **멀티 펫 겹침 순서**를 선택해 순서를 변경할 수 있습니다.

또한 **항상 위에 고정** 상태에서 여러 펫을 겹쳐 놓았을 때 서로 앞으로 올라오려고 순서가 반복해서 바뀌던 문제가 v4.1에서 수정되었습니다.

# 🎮 게임에서 사용하기

게임에서 키보드를 눌러도 Typing Pet이 반응하지 않는 경우, 게임이 관리자 권한으로 실행되고 있을 가능성이 있습니다.

다음 설정을 시도할 수 있습니다.

1. `TypingPet.exe` 우클릭
2. `속성`
3. `호환성`
4. **관리자 권한으로 이 프로그램 실행** 체크
5. Typing Pet 다시 실행

관리자 권한으로 실행하면 관리자 권한으로 실행 중인 게임에서도 키 입력을 감지할 수 있습니다.

> [!WARNING]
> 관리자 권한으로 실행하도록 설정하면 Windows 로그인 시 **자동 실행 기능이 동작하지 않을 수 있습니다.**

# 🔒 개인정보 보호

Typing Pet은 키보드 입력을 감지하지만 **어떤 글자를 입력했는지는 사용하지 않습니다.**

프로그램에서 사용하는 것은 단순히:

> **"키가 눌렸다"**

는 사실뿐입니다.

Typing Pet은 입력한 문자나 문장을:

- 저장하지 않습니다.
- 파일로 기록하지 않습니다.
- 네트워크로 전송하지 않습니다.

또한 Typing Pet 프로그램 자체는 **인터넷에 접속하지 않습니다.**

# 🛡️ Windows SmartScreen / 백신 경고

처음 실행할 때 Windows SmartScreen 경고가 나타날 수 있습니다.

이 경우:

`추가 정보 → 실행`

을 선택하면 실행할 수 있습니다.

공인 코드 서명 인증서로 서명되지 않은 개인 제작 프로그램에서 이러한 경고가 나타날 수 있습니다.

## 백신의 오탐 가능성

일부 백신 프로그램은 Typing Pet을 `Trojan:Script/Wacatac` 등의 이름으로 탐지할 수 있습니다.

Typing Pet은 다른 프로그램에서 입력하는 키에도 캐릭터가 반응하도록 **시스템 전체의 키보드 입력 발생 여부를 감지**합니다.

이와 같은 기능은 정상적인 프로그램과 키 입력을 감시하는 악성 프로그램이 모두 사용할 수 있기 때문에 일부 휴리스틱 또는 머신러닝 기반 백신 엔진이 민감하게 반응할 수 있습니다.

특히 탐지명 뒤에 `!ml` 등이 표시되는 경우 머신러닝 기반 분석 결과일 수 있습니다.

# 🔐 SHA-256 파일 검증

다운로드한 실행 파일의 SHA-256 값은 각 **GitHub Release에 안내된 체크섬**을 기준으로 확인해 주세요.

PowerShell에서 `TypingPet.exe`가 있는 폴더를 연 뒤 다음 명령을 실행할 수 있습니다.

```powershell
Get-FileHash .\TypingPet.exe -Algorithm SHA256
```

> [!IMPORTANT]
> 실행 파일이 변경되면 SHA-256 값도 변경됩니다.  
> 따라서 현재 버전의 GitHub Release에 표시된 SHA-256 값과 비교해 주세요.
